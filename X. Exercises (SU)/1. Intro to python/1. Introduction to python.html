1. Въведение в python¶

1.1. Защо python?¶

  • General purpose: python е език за програмиране с широко приложение. С него можем не само да построим един статистически модел, но и да изградим всичката периферна структура, която позволява този модел да бъде използван ан индустриално ниво.
  • Performance: модерните компютри са толкова мощни, че в повечето случаи няма особено значение. При работа с огромни масиви от високо размерни данни обаче, вече искаме да използваме възможно най-ефикасно изчислителните си ресурси.

1.2. Инсталация и среда за работа¶

Най-новата версия на python3 можем да свалим от https://www.python.org/downloads/. За да изполваме python за анализ на данни, е нужно да инсталираме допълнителни библиотеки. Това става с командата pip (ако имаме и старата версия python2 инсталирана на компютъра, трябва да ползваме pip3, за да покажем, че искаме да инсталираме библитеки за python3).

1.3. Основни концепции¶

Пълната документация на python можете да намерите тук. Ако имате някакъв проблем или въпрос и няма кого да питате, най-вероятно някой друг също го е имал преди вас - гугъл и stack overflow са най-добрите ви приятели в този случай.

Както всеки език за програмиране, python има основните концепции като променливи, колекции от данни, if/else проверки, цикли, функции и т.н. Ще се разпознаем накратко с тях:

1.3.1. Променливи¶

Можем да декларираме променливи, които сочат към обекти в паметта на компютъра с различни типове. Например, int (цяло число), float (реално число), str (текст), bool:

In [1]:
# int
a = 10
print(a)

# float
c = 6.3
print(c)

# str
b = "foo"
print(b)

# bool
d = True
print(d)
print(not d)

python е динамично типизиран език. Това означава, че промеливите нямат статичен тип и можем да ги предефинираме да сочат към друг тип обект:

In [2]:
v = 15
print(v)
v = 'bar'
print(v)

15
bar

Като използваме операторът = задачаме нова стойност на промеливата, т.е. сменяме обекта, към които тя сочи:

In [3]:

b = a
b = 10
# jupyter автоматично принтира резултатът от кода в клетката.
# Можем просто да кажем една променлива и ще я видим без print
a
Out[3]:

Виждаме, че a остава непроменена, понеже b = 10 заменя обекта (в този случай число), към които b сочи, с друг, а не променя оригиналния обект. Това е доста дълбока тема, неразбирането на която може да доведе до много бъгове, ако пишем по-сложни програми. Засега не би трябвало да имаме такива проблеми.

Можем да проверяваме типа на една променлива като използваме вградената функция isinstance:

set¶

set имплементира концепцията за множество. Подобно е на лист, но не е подредено. Използва се когато се интересуваме само дали даден елемент принадлежи на множество, без да се интересуваме от някаква подредба. Проверката дали даден елемент е в лист (ще го видим при if/else) става все по-бавна колкото повече елементи има в листа, но при сета не зависи от големината му. За сетове имаме дефинирани основните логически операции между множества.

break¶

В горния пример сумираме 1/n за числата до 100. Ако сместо това искаме да сумираме, докато вече s не се променя значително, т.е. 1/n е по-малко от някакъв епсилон eps, можем да използваме break. Така можем да прекъснем цикъла отвътре, ако дадено условие е изпълнено. (разбира се можем просто да сметнем колко трябва да е n за определено eps, но не се сетих за по-добър пример за break)

In [47]:
eps = 3.5e-7 # scientific notation 3.5 * 10^(-12)
s = 0
n = 1
while True: # този цикъл ще върви завинаги, ако не излезем от него с break
    one_over_n = 1/n
    if one_over_n <= eps:
        # спираме цикъла
        break
    s += one_over_n
    n += 1
print(f"The sum of 1/n for n from 1 to {n - 1} is {s:.2f}") # с :.2f опказваме само 2 знака след запетаята

The sum of 1/n for n from 1 to 2857142 is 15.44

continue¶

С continue можем да прескочим едно завъртане на цикъла. Ако в горния пример искаме да сумираме 1/n без тези n, които се делят на 7, можем да го направим с continue

In [48]:
s = 0
n = 1
while True:
    if not n % 7:
        n += 1
        continue
    one_over_n = 1/n
    if one_over_n <= eps:
        break
    s += one_over_n
    n += 1
print(f"The sum of 1/n for n from 1 to {n - 1} excluding multiples of 7 is {s:.2f}") # с :.2f опказваме само 2 знака след запетаята

The sum of 1/n for n from 1 to 2857142 excluding multiples of 7 is 13.51

Тук n % 7 връща 0, ако n се дели на 7, което като bool се счита за False. Обръщаме го с not пред него. Така ако n се делина на 7, просто увеличаваме n с едно и се връщаме в началото на цикъла.

1.3.10. Функции¶

Можем да дефинираме функции с ключовата дума def. Функциите могат да приемат аргументи (не е задължително) и да връщат резултат с ключовата дума return (не е задължително). Променливите дефинирани вътре във функцията не могат да се използват извън нея, но вътре във функцията можем да ползваме променливите от вън.

Когато стигнем до return, излизаме от функцията и останалата част от кода в нея не се изълнява. Ако не искаме резултатът от последната функция да става прекалено дълъг, можем да поставим условие за string и n, което ако не е изпълнено, да излизаме от функцията (не връщаме нищо).

In [63]:
def copy_string(string, n):
    if n * len(string) > 100:
        print('The result would be too long!')
        return
    # можем да "умножаваме" стрингове с цели числа, което просто повтаря стринга n пъти
    return string * n

Затова е много по-лесно да изпозлваме seaborn, където голяма част от този допълнителен год е вече написан от някого другиго. Например, ако искаме да направим графика на линейна регресия, това става с един ред на seaborn:
